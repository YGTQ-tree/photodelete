# 待删相机 · 使用指南

> 一句话：**随手拍的照片，到期自动进入「待删除」，一键清空。** 照片只存在你自己的手机/平板里。

## 1. 它是怎么工作的

```
拍照（勾选时长）→ 存在本应用自己的相册（沙箱）→ 到期自动进「待删除」→ 你点「一键删除」清空
                                     ↘ 想留下：点「保留」，它就永远不自动删
```

- **时长**：拍之前选 `1h / 6h / 24h / 72h / 永久`，只影响**这一张**（改设置不会追溯已拍的照片）。
- **默认 24 小时**，可在「设置」里改默认值。
- **删除前一定看得见**：照片先进入「待删除」列表，你确认后才真正删除，而且可以「保留」反悔。

## 2. 第一次使用

1. 打开「待删相机」→ 点「打开相机（拍照）」；
2. 首次会问**相机权限**，选「允许」（不给权限也没关系，其余功能照常可用）；
3. 选时长 → 按「拍照」→ 页面提示 `✅ 已保存：N 小时后转入待删除`。

## 3. 四个页面

| 页面 | 能做什么 |
|---|---|
| **相机** | 拍照；变焦 / 曝光 / 闪光 / 点按对焦 / 前后摄切换 / 网格线；右上角「我的照片」 |
| **我的照片** | 看**刚拍的、还没到期**的照片（含已保留的）。点一下**放大**看原图、左右滑动翻页；放大后可**分享**、**存进系统图库** |
| **待删除** | 到期照片都在这里。点一下放大查看；选中后「保留所选」或「一键删除」；不选=删除全部 |
| **设置** | 默认时长、到期提醒开关、后台整理状态 |

## 4. 分享 & 保存

- **分享给别人**：在「我的照片」里选中一张或多张 → 点「分享」→ 系统分享面板 → 选微信/邮件/…
  （照片直接从应用沙箱发给对方，**不需要先存进系统图库**。）
- **存进系统图库**：选中后点「保存图片」（安全控件，一次授权批量写入）；存完之后，其它应用「从相册选择」就能选到它们了。
- **导入**：点「导入」可从系统图库/系统截图里选图（一次最多 9 张）进入本应用管理。
- **多选**：点选即可；也可以**长按后滑动**，像相册一样连选。

## 5. 截屏

| 选项 | 说明 |
|---|---|
| **截屏含本页** | 直接截取本应用界面（例如把「待删除」列表留档），**任何设备都可用，不需要任何权限** |
| **截屏不含本页** | 想截别的内容（桌面、别的应用）时用它：会提示你**用系统截屏（电源+音量下，自带全屏/区域）**，然后**直接打开导入**，你刚截的图就在最前面，选中即纳管 |
| **截屏（系统框选，部分机型支持）** | 部分设备支持"应用内弹出系统框选界面"，有则可用、无则提示不支持；具体见下 |

> 为什么不能"一键截取不含本应用的画面"？因为系统**只允许前台应用发起截屏**，而前台时屏幕上必然有本应用界面。
> 所以「不含本页」由**系统截屏**承担（截图时本应用不在前台，天然不含本应用），本应用负责**导入并管理**它们。

## 6. 常见问题

**Q：为什么系统图库里看不到我拍的照片？**
A：为保护隐私，本应用**不申请读取/写入系统相册的权限**，照片存在应用自己的沙箱里。要看请用「我的照片」；
要给别人用，点「保存图片」存进系统图库或直接「分享」。

**Q：我用系统截屏/系统相机拍的，能自动清理吗？**
A：不能，那些照片属于系统图库，任何三方应用都无权删除（平台限制）。你可以把它们**导入**本应用，
导入后的副本由本应用管理（到期待删、一键删除）；系统图库里的原图需要你自己在系统图库里删。

**Q：删除会误删吗？**
A：不会自动删。到期只是把照片**移入「待删除」**，必须你按下「一键删除」并二次确认才会真的删除。

**Q：我的照片会上传吗？**
A：不会。本应用**没有网络权限**，所有处理都在设备本地完成。
