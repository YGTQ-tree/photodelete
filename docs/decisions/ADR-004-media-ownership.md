# ADR-004：照片归属与「自动删除」的边界（谁创建，谁管理）

- **日期**：2026-09-11
- **状态**：**已决定**（依据真机实测 + 华为官方答复/审核案例）
- **影响**：产品主张的表述、`AGENTS.md` 硬约束 2、T07 的范围

## 背景

产品最初的主张是「随手拍 → 用完自动整理删除」。真机上暴露出三个连锁问题：

1. 照片默认落在应用沙箱，**系统图库看不到**（微信/相册/分享都用不了）；
2. 要进图库只能靠安全控件，**一张张点**（已用批量+滑动多选解决，实测 7 张一次成功）；
3. **删除只删得掉沙箱副本**，导进系统图库的那份留在图库里 —— 原初主张对图库不成立。

## 我们做过的实测（本仓库自己的真机证据）

| 实验 | 结果 |
|---|---|
| 安全控件批量写入图库 | ✅ 一次点击连续写 7 张：`batch export: ok=7 fail=0` |
| 删除**自己用安全控件创建**的图库资产 | ❌ `201 Permission denied`（`MediaAssetChangeRequest.deleteAssets`） |

SDK 复核（`@ohos.file.photoAccessHelper.d.ts`）：`deleteAssets` 标注
`@permission ohos.permission.WRITE_IMAGEVIDEO`。
安全控件清单里**只有 `SaveButton` / `PasteButton`，没有 DeleteButton** ⇒ 平台不提供"用户点一下即授权删除"的等价物。

## 平台侧的权威结论（外部证据）

- 华为开发者答复（[原文存档](https://bbs.itying.com/topic/69bc3a3b6f4d61004c83f869)、[华为论坛同题](https://developer.huawei.com/consumer/cn/forum/topic/0210196098689159471)）：
  删除相册图片需要 `READ_IMAGEVIDEO` + `WRITE_IMAGEVIDEO`，而**这两个权限通常不允许三方应用申请**；
  `READ_IMAGEVIDEO` 仅**克隆/备份/同步**场景可申请，其它场景要求改用免权限替代方案。
- **同帖 2 楼是一个真实审核结果**：某"相册清理"类应用提交申请，AGC 审核意见为
  **「暂不支持图片删除功能，感谢支持！」** ⇒ 与我们场景完全一致的申请**已被拒过**。
- 同帖 4/5 楼给出的正确做法：**引导用户在系统图库内自行删除**；应用应遵循
  **「谁创建，谁管理」**，只管理自身产生/沙箱内的媒体数据。
- 受限权限申请流程见华为文档 [Restricted Permissions](https://developer.huawei.com/consumer/en/doc/harmonyos-guides-V5/restricted-permissions-V5)、
  [申请相册管理模块权限](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/photoaccesshelper-preparation)；
  调试阶段可用 **DevEco 自动签名**代为申请 ACL 受限权限（本机无官方 Linux IDE，走不到这条路）。

## 决定

**采用「沙箱即本应用的相册」模型，放弃"删除系统图库照片"这一目标。**

1. 照片由本应用拍摄并保存在**自己的沙箱**（= 我们自己的相册，符合"谁创建谁管理"）；
   到期整理与一键删除**只在沙箱内生效** —— 这也是产品的核心价值，且不需要任何受限权限。
2. **系统图库是"用户资产区"**：我们只能**一键批量存入**（安全控件，已验证），
   **不能删除**；需要清理时按平台建议**引导用户在系统图库内删除**。
3. 因此**不申请** `READ_IMAGEVIDEO` / `WRITE_IMAGEVIDEO`（`AGENTS.md` 硬约束 2 保持不变），
   并且把"申请受限权限"从候选路线中**移除**（有被拒的先例，且与本产品的清理类场景不符）。
4. 产品表述相应修正：不是"删除你相册里的照片"，而是
   **「本应用拍的照片，到期自动进入待删除、一键清空」**；想要留存就存进系统图库（之后归用户管）。

## 后果

- ✅ 守住零受限权限：上架审核不会被权限用途卡住。
- ✅ 「拍 → 到期 → 一键删除」闭环完整且真机验证过（A1/A3/A4/A5/A6）。
- ⚠️ 用户若把照片导出到图库，本应用**无法**再代为清理（平台禁止，非实现缺陷）。
  缓解手段：`我的照片` 页支持批量导出；后续可加"打开系统图库"引导入口（免权限的 `want viewData`）。
- ⚠️ 截图/系统相机拍的照片同样**不在**本应用管辖内（它们天然属于系统图库，由用户管理）。
