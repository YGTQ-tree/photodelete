## 当前阻塞（都需要人工）

1. **手机未插线**：`hdc list targets` 为 `[Empty]`、`lsusb` 查不到华为设备 → G0-A-3 及之后全部排队。
2. **无华为开发者账号**：签不出含本机 UDID 的调试证书 → 无法装机 → G0-A-4、G0-B、T03–T06 排队。

在两者解开前，可推进：领域层扩展、存储/设置实现（已完成编译验证）、配置检查、文档，以及用假实现驱动的 UI 骨架。

## 为什么不按 T00→T01→… 串行

T00 的门禁受**下载速度、华为账号、手机开发者模式**等外部因素影响，可能是最长的一段等待。T01 的领域层是纯 TS，不需要 SDK 和真机，**必须并行推进**——这样即使 G0-A 卡住，项目也在实质前进。
